# Кабинет студента

Локальное настольное приложение для учёта студентов, оценок, расписания,
посещаемости, договоров и объявлений. Интерфейс поддерживает русский и
таджикский языки. Данные хранятся локально в SQLite; подключение к серверу
или интернету для работы не требуется.

## Запуск в Windows

Откройте PowerShell в папке проекта и выполните:

```powershell
py -3 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe main.py
```

При первом запуске создаётся локальная база `student_cabinet.db` и учётная
запись администратора: `admin` / `admin123456`. После входа смените пароль в
меню слева. Если база уже существует, приложение сохраняет её пользователей
и записи; начальные данные повторно не добавляются.

Учётные записи студентов создаются администратором в разделе «Студенты».
Новый студент получает личный кабинет после создания его карточки.

## Первый запуск и работа администратора

1. Откройте «Справочники» и добавьте учебные группы, предметы, специальности,
   курсы и семестры.
2. В «Студентах» создайте карточку и задайте логин и пароль. Карточку можно
   редактировать, а доступ студента — временно отключать и включать.
3. Добавьте оценки, занятия, отметки посещаемости и договоры.
4. Регистрируйте оплаты по созданному договору; сумма не может превышать
   остаток договора.
5. Публикуйте объявления для всех студентов или выберите одну группу.
6. Выгружайте таблицы в Excel из соответствующих разделов.

Студенческий кабинет показывает профиль, оценки, расписание, посещаемость,
договоры и объявления, доступные его группе.

## Данные и резервное копирование

База находится в `student_cabinet.db` рядом с `main.py`. Для резервного
копирования закройте приложение и скопируйте этот файл в безопасное место.
Иллюстрация интерфейса находится в `assets/campus_illustration.ppm` и
использует встроенную поддержку изображений Tkinter.
